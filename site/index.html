It follows your agent, not a timer.

If your Mac sleeps halfway through a long run, the agent stops. With a classic keep-awake app you pick “2 hours” and hope you guessed right. Wick watches what your agents are actually doing.

Working

An agent starts a task, the flame lights up and your Mac stays awake. Several sessions at once? It keeps track of all of them.

Waiting for you

The agent needs your approval. The candle in the menu bar turns orange so you notice, and your Mac is free to rest until you answer.

Resting

The work is done. Wick waits two more minutes in case the agent picks up again, then lets your Mac sleep as usual.

Works with the agents you already use.

Claude Code is followed through hooks, so Wick knows exactly when it works, when it needs you and when it's done. Other terminal agents are detected by their process: if they, or the commands they run, are busy, they're working.

Lid closed

Close it, take it with you

Optional. One password, then lid sleep is disabled only while an agent works. It always comes back when the work ends, when you quit, if the app crashes, or below 15% battery.

Install in a minute.

  1. Download Wick.zip, unzip it and drag Wick.app into Applications.
  2. Open it. Wick isn't signed with an Apple Developer ID yet, so macOS warns you the first time: go to System Settings → Privacy & Security and click Open Anyway.
  3. If you use Claude Code, Wick offers to add its hooks for exact tracking. It backs up ~/.claude/settings.json first and you can remove them from the menu.

Questions

Does Wick only work with Claude Code?

No. Claude Code is followed through hooks, which is the most precise. Codex, Gemini CLI, Cursor Agent, OpenCode, Aider, Amp, Goose and other terminal agents are detected by their process: if the agent or the commands it runs are using CPU, Wick treats it as working.

Why does macOS warn me when I open it?

Wick isn't signed with an Apple Developer ID yet. Open it once, then go to System Settings → Privacy & Security and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Wick.app.

Why does it ask for my password?

Only for lid-closed mode. macOS doesn't let a normal app stop lid sleep, so Wick starts a small helper with administrator rights that turns it on and off with your agent. It never asks otherwise.

Is lid-closed mode safe?

Wick restores normal sleep when the agent finishes, when you quit, if the app crashes and below 15% battery. Keep your Mac somewhere it can breathe: a closed laptop in a bag gets warm.

What does it change in my Claude Code settings?

It adds a few hooks to ~/.claude/settings.json that call ~/.wick/hook. The hook saves the session state and exits in milliseconds; it never blocks Claude Code or changes what it does. Your other hooks stay untouched, and turning the option off removes Wick's.

Does Wick collect any data?

No. No network, no analytics, no account. Session state lives in ~/.wick on your Mac.

Is it free?

Yes, free and open source under the MIT license. It started from Caffeinator by Jon Kraayen and is made by Cometa Labs.
